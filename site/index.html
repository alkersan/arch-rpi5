Arch Linux for Raspberry Pi 5

Pre-built disk images from the Arch Linux AArch64 Port.

About

Unofficial Raspberry Pi 5 images with a basic headless system, made from drzee.net (ARMv8.2+) repo. See sources on GitHub.

  • only base packages with few extras, no desktop environment
  • no default user and password
  • Ethernet configured for DHCP network
  • root filesystem expands to the entire disk on first boot
  • used mkosi profiles: linux-rpi5, firstboot, growfs, ssh

Writing an image

Download image and checksum file. Check the download before writing:

sha256sum --check *.SHA256SUMS

Extract the .img.xz image and write to an SD card, USB or NVME drive with a disk image writer.

First boot

Before boot, put a file named first-boot into the boot partition. Use this bash script to create user accounts, SSH keys, etc. See the setup example in the README.
